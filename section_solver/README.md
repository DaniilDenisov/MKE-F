# Расчёт сечений MKE-F

```python
from section_solver import Profile
from section_solver.engine import Engine, Options
from section_solver.member import member, planar, truss
from section_solver.recovery import point

profile = Profile.from_section({"type": "rectangle", "dimensions": {"h": 2, "b": 1}})
session = Engine()
load = [0.1, 1, -0.31, 0.17, 0.09, -0.06]
r = session.solve(profile, 0.3, load, J_model=0.45)
if r["fieldStatus"] == "ok":
    stress = point(r["kernel"], load, y=0.1, z=0.2)
if r["maximumStatus"] == "ok":
    peak = r["maximum"]
along = member(session, profile, 0.3, planar([0], [1,-2], [0,1,-1], angle=90))
axial = truss([-1,4,-4], area=2)
```

Размеры и координаты вводятся в единой единице длины, силы и моменты — в согласованных единицах. Высота `h` направлена по y, ширина `b` по z. Усилия идут в порядке `[N,Vy,Vz,T,My,Mz]`. Полиномы задаются коэффициентами от свободного члена до кубического по `xi=x/L`. Пространственные усилия задаются в осях сечения. Для плоских усилий `planar` принимает угол в градусах.

`Engine` обслуживает последовательные запросы. Экземпляр хранит сетки для геометрии и единичные поля для каждой сетки и ν. Новый экземпляр начинает с пустого кэша. `Options` ограничивает уровни, треугольники, время, оценку памяти с кэшем и число ячеек поиска. Пакет проверяет отмену между вызовами нативного решателя и в вычислительных циклах. Параметр `cancelled` — функция без аргументов.

`history` показывает ошибки геометрии, изменения трёх единичных полей в L2, J и максимума по уровням. `relative_gap` и `upper` относятся к поиску на выбранной сетке. Для результата по длине `section_upper` относится к критическому сечению. Запрос точки на общей границе выбирает минимальный номер треугольника. Параметр `element` выбирает другую сторону. Для труб с острым внутренним углом `maximumStatus="unavailable"` при сдвиге и кручении, а `mesh_peak` содержит диагностический максимум. При остановке доступны результаты последних завершённых уровней.

Полная численная приёмка из корня репозитория в PowerShell:

```powershell
./scripts/section_solver_acceptance/run.ps1
```

Сценарий запускает проверки в Docker и записывает отчёт в новый каталог `output/section-solver/`. Холодный расчёт и повторные нагрузки измеряются раздельно. Для круга, кольца и прямоугольника сравниваются аналитические поля, J и пики, а также фиксируются время и пиковый RSS процесса Python. Для острых труб J сверяется с независимым конечно-разностным решением. Замеры относятся к машине, на которой выполнен сценарий.
