# Changelog

Основные изменения после перехода проекта на GNU Octave.

## [Unreleased]

- Завершено разделение геометрии сечения, предварительных расчётов редактора
  и чтения свойств решателя. Неиспользуемый расчёт статических напряжений 2D
  перенесён из приложения в независимый тестовый помощник.
  Экспорт JSON сохраняет малые ненулевые double, которые нативный jsonencode
  Octave мог обнулять; добавлены побитовые проверки, пересчитаны четыре примера.
  Зафиксированы границы оставшихся вычислений и замеры ресурсов 2D/3D.
- Характеристики назначенных сечений в v8 копируются из модели решателя:
  A, Iy/Iz, центр тяжести, крайние волокна и принятый J с его методом.
  Статические экстремумы нормальных напряжений и критические сечения 2D/3D
  берутся из Octave без повторного поиска в браузере. Вычисление поля в точке,
  динамический поиск и предварительные расчёты редактора сохранены.
  Добавлены 42 контрольных случая и проверки SVG/CSV, окраски и запросов Мизеса.
- Экспорт, API и просмотрщик переведены на единый JSON v8. Старые результаты
  v1–v7 больше не открываются: требуется пересчёт исходного TXT. Удалены
  режим экспорта `legacy`, адаптер K/M v7 и старое построение эпюр в браузере.
  Численные тесты используют свежие v8. Для неподдерживаемого формата выводится
  «Unsupported format. Recalculate.»; архивные JSON и отдельные тесты v1–v7 удалены.
- v8 поддерживает 2D-фермы и рамы: матрицы K/M решателя,
  кинематика освобождённых концов, MPC, статические коэффициенты N/V/M,
  модальные и частичные переходные данные. Новый 2D-путь использует готовые
  коэффициенты и статические экстремумы в просмотрщике. Добавлены 23 случая
  и Docker-проверки численного восстановления и интерфейса.
- В v8 добавлена общая таблица строго одинаковых локальных пар K/M
  со ссылками элементов по ID. Автоматический выбор сохраняет прежнее хранение,
  если таблица не уменьшает компактный JSON. Браузер использует общие матрицы
  без размножения; добавлены Docker-проверки и замеры размера, памяти и времени.
- JSON v8 для пространственных результатов: локальные
  матрицы K/M экспортируются из Octave и используются для восстановления
  модальных и переходных усилий в браузере.
- Единый Docker-конвейер проверки операторов на свежих результатах v8
  с замерами чтения JSON в браузере.

## [0.8.5] - 2026-11-04

- Поддержка пространственных ферм и рам: редактор геометрии и условий, статический, модальный и переходный расчёты, просмотр и экспорт результатов.
- Единая WebGL-сцена для 2D/3D: навигация, редактирование, деформации и эпюры. Результат открывается кнопкой Open result в отдельной вкладке; модель и история Undo/Redo сохраняются.
- Каталог сечений для 3D, восстановление нормальных напряжений и окраска статических результатов 2D/3D по максимальному |σx|. Новые расчёты пространственных рам допускают сплошной круг, прямоугольник, круглую, квадратную и прямоугольную трубы; старые результаты открытых профилей доступны для просмотра.
- Экспериментальный FEM-модуль сечений на `sectionproperties`: кручение и сдвиг для тех же пяти форм с контролем сходимости, диагностическая страница и максимумы напряжений Мизеса по стержням в статическом постпроцессоре. Сервис сечений включён в готовую Docker-сборку. [Возможности и ограничения](reference/RU/08-result-recovery.html#section-fem-title).
- Руководство и проверенные примеры 3D в русском и английском справочниках.

## [0.8.4] - 2026-10-18
