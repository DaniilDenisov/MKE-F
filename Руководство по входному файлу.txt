Строка 1-5: Узлы сначала указано кол-во (3), далее
координаты построчно X,Y,Z.

Строка 6-9: Элементы типа 113 (двухмерная балка)
Количество элементов равно 2, формат строки:
[Тип элемента, узел 1, узел 2, площадь, модуль Юнга,
плотность, момент инерции (изгиб)].

Строка 10-12: ГУ заделки (кол-во=1). Формат строки:
[Тип ГУ, номер узла, по X, по Y, по Z]
Тип=1, номер узла, X=Y=Z=0 - для заделки всех СС.
Тип=2, номер узла, X=Y=Z=0 - для заделки по вертикали (гор. сс свободна)
Тип=3, номер узла, X=Y=Z=0 - для заделки по горизонтали (верт. сс свободна)

Строка 13-15: ГУ приложенной нагрузки (стат.). Формат строки:
[Тип ГУ, номер узла, Fx, Fy, Mz]

МКЭ-Ф решает плоскую задачу в глобальной плоскости X-Y. Поэтому силы Fz и
перемещения uz нет. У рамного узла три СС [ux,uy,θz], а сопряжённые узловые
нагрузки имеют вид [Fx,Fy,Mz]. Момент Mz действует вокруг оси Z и вызывает
изгиб в плоскости X-Y. У ферменного узла только [ux,uy] и [Fx,Fy], поэтому
пятое поле строки нагрузки должно быть равно нулю.

Поддерживаемые маркеры и типы узловой нагрузки:

bcforce_stat, тип=10. В RunStatic это постоянная статическая нагрузка. Для
обратной совместимости в RunTransient тот же тип действует только на первом
шаге как прямоугольный импульс. Его дискретный импульс равен F0*dt.

bcforce_harm, тип=11. Формат:
[11, номер узла, Fx, Fy, Mz, частота в Гц]
На каждом шаге компоненты равны F0*sin(2*pi*f*t).

bcforce_pulse, тип=12. Явно заданный прямоугольный импульс, действующий только
на первом шаге RunTransient. Формат:
[12, номер узла, Fx, Fy, Mz]

bcforce_step, тип=13. Постоянная ступенчатая нагрузка, действующая на всех
столбцах времени RunTransient, включая t=0. Формат:
[13, номер узла, Fx, Fy, Mz]

Несколько строк в одном блоке суммируются. Допускаются несколько нагрузок в
одном узле и нагрузки в разных узлах.

Запуск:

P1 = StructFEProblem('CaseFig11.7p363 MarioPaz.txt');
P1.RunModal();
P1.RunTransient(0.0005,2.5,2,1);

Блок nodes: узлы и их координаты.

Блок bcfix: ГУ заделки двух узлов. 1-го по всем СС (тип=1)

далее компоненты Fx=0,Fy=-1000; последнее поле компоненты равно нулю, потому
что у ферменного узла нет вращательной СС; частота=140Гц.

Запуск:
P1 = StructFEProblem('CaseAStaticSite.txt');
P1.RunStatic();
P1.RunTransient(0.0000005,0.2,5,2);
P1.RunModal();

Статический, модальный и переходный расчёты можно запускать в любом порядке:
решатели не изменяют собранные матрицы жёсткости и масс.

В переходном результате столбец 1 всех историй соответствует t=0, столбец 2
соответствует t=dt. Истории нагрузки, перемещений, скоростей и ускорений имеют
одинаковое число столбцов tsNum+1. Нагрузка типа 10 или 12 записывается только
в столбец 2 и поэтому имеет дискретный импульс F0*dt.

Метод Ньюмарка использует beta=1/4 и gamma=1/2. Начальные перемещения и
скорости можно передать в options.initialDisplacement и
options.initialVelocity; начальное ускорение вычисляется из равновесия.
Использованный открытый источник формул:
https://people.duke.edu/~hpgavin/StructuralDynamics/NumericalIntegration.pdf
