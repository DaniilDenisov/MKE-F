# Поле напряжений в сечении

В сборке Docker Compose из исходников [диагностическая страница](section-fem-lab.html) передаёт геометрию, коэффициент Пуассона и усилия в Python. Библиотека `sectionproperties` строит сетку Tri6 и решает задачи кручения и поперечного сдвига Сен-Венана. MKE-F объединяет три единичных поля с фактическими усилиями.

## Оси и восстановление

Координаты отсчитываются от центра сечения, ось x направлена вдоль стержня. Размер h направлен по y, b по z. Порядок усилий — [N, Vy, Vz, T, My, Mz]. Величины задаются в согласованных единицах, например м, Н и Н·м. Тогда напряжения получаются в Па.

```
σx = N/A + My z/Iy − Mz y/Iz
[τxy, τxz] = Vy qVy + Vz qVz + T qT
σVM = sqrt(σx² + 3(τxy² + τxz²))
```

Площадь и моменты инерции берутся по аналитической геометрии. Касательные напряжения вычисляются в шести локальных узлах каждого элемента. Соседние элементы могут дать разные напряжения на общем ребре. На карте это различие сохраняется.

## Сходимость и отображение

При сгущении сетки ядро сравнивает J и три поля в общих физических точках. Для конечного численного пика требуются два последовательных изменения в пределах 0,5%. На одной сетке верхняя оценка по коэффициентам Бернштейна ограничивает ошибку поиска. В отчёте приведены обе оценки. При остановке по бюджету доступна диагностика последнего завершённого уровня.

Для острых квадратных и прямоугольных труб ненулевой сдвиг или кручение дают статус глобального максимума `unavailable`. Маркер показывает пик на конечной сетке. При растяжении и изгибе конечный максимум определяется по углам профиля.

Для изображения Python вычисляет четыре компоненты на 15 точках каждого треугольника. Браузер интерполирует значения внутри 16 подтреугольников, а линии сетки показывают исходные элементы. Пик ищется отдельно на исходном квадратичном поле. Цвет шкалы соответствует выбранной компоненте и текущей нагрузке.

## Проверка

Команда `./scripts/section_solver_acceptance/run.ps1` проверяет пять профилей в Docker, включая равновесие, поля по L2, крутильную постоянную и конечные пики. Эталоны используют решения для сплошного круга и кольца, ряды для прямоугольника и независимое конечно-объёмное решение для острых труб. Исторические измерения JS относятся к коммиту `f355300` и более ранним версиям.
