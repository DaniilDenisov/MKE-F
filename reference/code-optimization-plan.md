#### 4.3. Поиск вещественных корней для экстремумов напряжений

Существенное различие — допуск мнимой части `1e-8` в 2D и `1e-7` в 3D. Плоская версия также явно возвращает пустой результат для постоянного полинома, а пространственная передаёт его в `roots`.

Вызов проходит через `solveStatic → recoverElementResults → recover*SectionStress` для назначенного сечения. Пример [3D: быстрый старт](RU/3d-quick-start.html) использует эту цепочку. В лабораторных 07 и 08 исходные TXT не назначают сечения, поэтому успешный запуск этих двух занятий сам по себе не проверяет изменяемый поиск корней.
