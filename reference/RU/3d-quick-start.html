Краткое руководство

3D: быстрый старт

Основы пространственного расчёта: выбор элемента, редактор, сечение и чтение результата. Прежние лабораторные 2D используют типы 112/113 и сохраняют свой порядок работы.

1. Какой элемент выбрать

КодМодельСС на узел
112Плоская фермаux, uy
113Плоская рамаux, uy, θz
1133Пространственная ферма: растяжение/сжатиеux, uy, uz
1436Пространственная рама: растяжение/сжатие, два изгиба, кручениеux, uy, uz, θx, θy, θz

Выбирайте ферму для стержней, передающих только продольное усилие, раму — для изгиба и кручения. Семейства нельзя смешивать в одной модели. Размерность определяется кодом элемента: ненулевая Z сама по себе не превращает 112/113 в 3D. Свойства кодов заданы реестром; программа не разбирает цифры кода.

2. Координаты и сечение

Узлы задаются глобальными XYZ. Локальная X направлена от первого конца стержня ко второму. Опорный вектор Y проецируется перпендикулярно X; Z дополняет правую тройку. Опорная Y не должна быть параллельна стержню. Угол в градусах поворачивает Y/Z вокруг X.

В собственных осях профиля Y соответствует высоте, Z — ширине; начало находится в центре тяжести. Для рам 1436 доступны прямоугольник, круг, квадратная, прямоугольная и круглая трубы. Фермы 1133 и модели 2D сохраняют все восемь профилей, включая швеллер, тавр и двутавр. Каталог задаёт A для фермы и A, Iy, Iz, J для рамы; материал E, ρ и G остаётся свойством элемента.

Открытые профили исключены из новых назначений и расчётов рам: модель не учитывает смещение центра сдвига и стеснённую депланацию. Старые TXT можно открывать и исправлять; перед любым расчётом нужно заменить назначенные открытые профили. Неиспользуемые записи каталога расчёт не блокируют, сохранённые JSON-результаты доступны для просмотра. Ручные характеристики без геометрии сечения разрешены, но применимость профиля при этом не проверяется. Для разрешённых профилей сохраняются описанные ниже ограничения балочной теории и приближения J.

У рамы один итоговый угол: вместе с профилем поворачиваются локальные нагрузки и освобождения. Глобальные нагрузки и коэффициенты MPC сохраняются. Поворот профиля фермы условный и не меняет её жёсткость. Снятие назначения сохраняет численные свойства, но убирает возможность вычислять напряжения по профилю.

3. Первый расчёт в редакторе

Скачайте CaseSpatialQuickStart.txt и откройте в препроцессоре. В локальном справочнике ссылка может открыть TXT напрямую; выберите тот же файл из папки examples/cases через «Open TXT». Это консоль длиной 2 м с прямоугольником 0,1 × 0,2 м, E = 200 ГПа и силой Fy = −1000 Н на свободном конце.

  1. Осмотрите модель. Левой кнопкой вращайте вид, правой или Shift + левой перемещайте, колесом масштабируйте. Fit model подбирает масштаб; Reset to origin возвращает XY при Z = 0 и центр (0,0,0).
  2. Выберите узел в таблице или на сцене. Измените XYZ, примените и попробуйте undo/redo. Для возврата к контрольному примеру отмените правку.
  3. При добавлении узлы размещаются на рабочей плоскости XY/XZ/YZ с заданным смещением. Привязка использует базовый шаг сетки, даже когда видимая сетка укрупнена. Точный XYZ не округляется. Перемещение узла идёт в параллельной плоскости через исходную точку; Escape отменяет жест.
  4. Кнопка Materials and Sections открывает окно поверх сцены. Подготовьте профили и материал для новых стержней, затем закройте окно. По умолчанию задана сталь: E = 210 ГПа, ρ = 7850 кг/м³, G ≈ 80,77 ГПа (ν = 0,3). Изменение этих настроек не меняет уже созданные стержни. В режиме Add Element выберите сечение: A/Iy/Iz/J заполнятся автоматически. Щёлкните по двум существующим узлам либо введите номера концов и нажмите Create element. Без каталога свойства вводятся числами.
  5. Списки узлов, стержней и условий находятся справа. Выберите стержень, откройте каталог, проверьте назначение сечения 1 и попробуйте произвольный угол. Для контрольного результата верните 0°. В правой панели откройте «Отображение сечений»: контуры, локальные оси, их количество и масштаб меняют только рисунок.
  6. Выберите опору узла 1: закреплены все шесть компонент. В нагрузке узла 2 задано только Fy = −1000. Новые условия назначаются инструментом на узел/стержень либо точным вводом номера, затем применяются одной операцией.
  7. При доступном API запустите статический расчёт. Кнопка «Открыть результат» открывает отдельную вкладку; редактор и история сохраняются. Если модель менялась во время расчёта, результат относится к отправленному снимку.

Через file:// доступны редактор и просмотр JSON. Запуск расчёта требует HTTP и настроенного API; см. запуск проекта. Без WebGL остаются формы, таблицы, графики и SVG-разрез, но отсутствует пространственная сцена.

Можно выполнить тот же файл в Octave из корня проекта:

addpath(pwd);
setup;
problem = StructFEProblem(exampleCasePath('CaseSpatialQuickStart.txt'));
model = problem.GetAnalysisModel();
result = problem.RunSelected();
exportPostprocessorData(model, result, 'output/CaseSpatialQuickStart.json');

4. Что смотреть в результате

Без правок примера ожидается uy узла 2 = −0,0002 м (−0,2 мм), реакция Fy у опоры = +1000 Н, а крайние нормальные напряжения у заделки — ±3 МПа. Перемещения заданы в единицах длины, физические повороты — в радианах. Визуальное увеличение деформации численные значения не меняет.

Для рамы доступны N, Vy, Vz, Mx, My, Mz, для фермы — N и N/A. Концевые действия, усилия в сечении, реакции опор и силы MPC — разные величины. Выбор стержня открывает график по длине и, при назначенном профиле, разрез Y вверх / Z вправо, вид со стороны −X.

σx(x,y,z) = N(x)/A + My(x)·z/Iy − Mz(x)·y/Iz

Это нормальные напряжения от продольной силы и двух изгибов. Угол уже учтён локальным базисом. Отверстия не являются материалом; без каталога остаётся N/A. Доступны σmin/σmax, выбор материальной точки, SVG-разрез и CSV; для сцены — PNG.

В собственных формах амплитуда условная, а фаза меняет знак перемещений, усилий и напряжений. В transient показываются сохранённые кадры; вся история занимает 5 с просмотра при 1×, расчётное время указано отдельно. Есть истории, спектры физических перемещений/вращений и история σx выбранной точки. Недостающие поля частичного JSON не заменяются нулями. На освобождённом конце динамический упругий момент может компенсироваться инерционным.

Другие готовые примеры: собственные формы и переходный процесс. Они используют численные свойства; для полного разреза назначьте профиль и пересчитайте модель.

5. Границы расчётной модели

Линейная упругость и малые перемещения. Рама Эйлера–Бернулли: без деформаций поперечного сдвига; кручение Сен-Венана: без стеснённой депланации. Нет пластичности, геометрической нелинейности, автоматических эксцентриситетов и учёта центра сдвига. Открытый профиль и ручной J этих ограничений не снимают.

Тонкостенные J для труб прямоугольного сечения и открытых профилей приближённые; метод показан в каталоге. При ручном J изменение размеров не пересчитывает J. Крутильная инерция массы использует ρ(Iy + Iz), а не ρJ. Для статики доступна окраска по максимальному модулю нормального напряжения от продольной силы и изгибов, без сдвига и кручения. Максимумы Мизеса по стержням доступны в боковой панели статики; экспериментальный FEM сечения запускается отдельно. Стеснённая депланация и сортамент ГОСТ не поддерживаются.

Поддержаны однородные опоры, линейные MPC и локальные освобождения Mx/My/Mz рам. Распределённые нагрузки равномерные или линейные, только на полной длине рам и только в статике. В modal нагрузки не задаются. В transient тип 10, как и 12, действует один шаг; для постоянного воздействия нужен тип 13. Newmark работает без демпфирования (β = ¼, γ = ½). Собственный вес автоматически не добавляется.
