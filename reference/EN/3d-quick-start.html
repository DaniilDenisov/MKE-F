Quick guide

3D: quick start

The essentials of spatial analysis: element choice, editing, sections and results. Existing 2D labs continue to use types 112/113 and the same workflow.

1. Choose an element

CodeModelDOFs per node
112Plane trussux, uy
113Plane frameux, uy, θz
1133Spatial truss: axial tension/compressionux, uy, uz
1436Spatial frame: axial, two bending components and torsionux, uy, uz, θx, θy, θz

Choose a truss for members carrying axial force only, or a frame for bending and torsion. Families cannot be mixed in one model. The element code determines dimension: nonzero Z alone does not turn 112/113 into 3D. A registry defines each type; the software does not parse the digits of the code.

2. Coordinates and sections

Nodes use global XYZ. Local X runs from the first member end to the second. The reference Y vector is projected perpendicular to X; Z completes a right-handed triad. Reference Y must not be parallel to the member. The angle, in degrees, rotates Y/Z about X.

In the profile's own axes, Y is height, Z is width and the origin is the centroid. Frames 1436 accept a rectangle, solid circle, square, rectangular and circular tubes. Trusses 1133 and 2D models retain all eight profiles, including channel, tee and I section. The catalog supplies A for a truss and A, Iy, Iz, J for a frame; material E, ρ and G remain element properties.

Open profiles are excluded from new frame assignments and calculations because shear-center offsets and restrained warping are not modeled. Legacy TXT models remain editable: replace assigned open profiles before running any analysis. Unused catalog entries do not block calculation, and saved JSON results remain viewable. Numerical properties without section geometry remain available, but profile applicability cannot be checked. The permitted profiles still have the beam-theory limitations and J approximations described below.

A frame has one final angle: local loads and releases rotate with the profile. Global loads and MPC coefficients remain unchanged. Truss profile orientation is illustrative and does not change stiffness. Detaching a profile keeps numerical properties but removes full section-stress recovery.

3. Your first editor calculation

Download CaseSpatialQuickStart.txt and open it in the preprocessor. In the local reference, the link may open the TXT directly; use Open TXT to select the same file from examples/cases. It is a 2 m cantilever with a 0.1 × 0.2 m rectangle, E = 200 GPa and a tip force Fy = −1000 N.

  1. Inspect the model. Drag with the left button to rotate, right or Shift + left to pan, and use the wheel to zoom. Fit model adjusts the scale; Reset to origin returns to XY at Z = 0, centered at (0,0,0).
  2. Select a node in the table or scene. Apply an XYZ change and try undo/redo. Undo the edit to return to the reference example.
  3. New nodes lie on the XY/XZ/YZ work plane with its chosen offset. Snapping uses the base grid step even when displayed grid spacing is enlarged. Exact XYZ input is not rounded. Moving a node uses a parallel plane through its original point; Escape cancels the gesture.
  4. Materials and Sections opens a window over the scene. Prepare profiles and material defaults for new members, then close it. The default is steel: E = 210 GPa, ρ = 7850 kg/m³, G ≈ 80.77 GPa (ν = 0.3). Changing these settings leaves existing members unchanged. In Add Element mode, choose a section: A/Iy/Iz/J are filled automatically. Click two existing nodes or enter both node numbers and press Create element. Without a catalog section, enter numerical properties.
  5. Nodes, members and conditions are listed in the right sidebar. Select the member, open the catalog, check section assignment 1 and try any rotation angle. Restore 0° for the reference values. Section display settings in the right sidebar control contours, local axes, their count and visual scale; these affect the drawing only.
  6. Inspect node 1's support: all six components are fixed. Node 2 has Fy = −1000 only. New conditions are assigned with a tool on a node/member or by entering its number, then applied as one operation.
  7. With an available API, run static analysis. Open result creates a separate tab, preserving the editor and its history. If you edited while the calculation ran, the result belongs to the submitted snapshot.

The editor and JSON viewer work through file://. Running calculations requires HTTP and a configured API; see project setup. Without WebGL, forms, tables, charts and the SVG section remain available, but the spatial scene does not.

You can run the same file in Octave from the project root:

addpath(pwd);
setup;
problem = StructFEProblem(exampleCasePath('CaseSpatialQuickStart.txt'));
model = problem.GetAnalysisModel();
result = problem.RunSelected();
exportPostprocessorData(model, result, 'output/CaseSpatialQuickStart.json');

4. Read the results

Without edits, expect node 2 uy = −0.0002 m (−0.2 mm), support Fy = +1000 N and extreme normal stresses of ±3 MPa at the fixed end. Displacements use length units; physical rotations are in radians. Visual deformation magnification does not change numerical values.

Frames provide N, Vy, Vz, Mx, My, Mz; trusses provide N and N/A. End actions, section forces, support reactions and MPC forces are distinct quantities. Selecting a member opens its length chart and, with an assigned profile, a section view: Y up, Z right, viewed from −X.

σx(x,y,z) = N(x)/A + My(x)·z/Iy − Mz(x)·y/Iz

These are normal stresses from axial force and biaxial bending. The local basis already includes the angle. Holes are not material; without a catalog profile, only N/A is available. You can inspect σmin/σmax, select a material point, export section SVG/CSV and capture scene PNG.

Mode amplitudes are arbitrary; phase changes the signs of displacements, forces and stresses. Transient playback shows saved frames; the full history takes 5 seconds of viewing at 1×, with calculation time shown separately. Histories, physical displacement/rotation spectra and point σx histories are available. Missing fields in partial JSON are not replaced by zeros. A released end's dynamic elastic moment may be balanced by inertia.

Further examples: modes and transient response. They use numerical properties; assign a profile and rerun to obtain a full section view.

5. Model limitations

Linear elasticity and small displacements. Euler–Bernoulli frames omit transverse shear deformation; Saint-Venant torsion omits restrained warping. Plasticity, geometric nonlinearity, automatic eccentricities and shear-center offsets are not included. An open profile or a manual J does not remove these limitations.

Thin-wall J values for rectangular tubes and open profiles are approximate; the catalog shows the method. Resizing a profile does not recalculate manual J. Torsional mass inertia uses ρ(Iy + Iz), not ρJ. Static results support maximum absolute normal stress coloring from axial force and bending; shear and torsion are excluded. Per-member von Mises maxima are available in the static results sidebar; experimental section FEM runs separately. Restrained warping and GOST standard-size catalogs are not supported.

Homogeneous supports, linear MPC and local frame releases Mx/My/Mz are supported. Distributed loads may be uniform or linear, on full-length frames in static analysis only. Modal analysis has no applied loads. In transient analysis, type 10 acts for one step, like type 12; use type 13 for a constant load. Newmark is undamped (β = ¼, γ = ½). Self-weight is not added automatically.
