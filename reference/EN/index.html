Learning route

2. Element matrices

4. Boundary conditions and loads

Separate free and constrained DOFs, match forces to displacements and construct four load histories.

4a. Linear multipoint constraints (MPC)

Define relationships between DOFs, eliminate dependent displacements and interpret MPC forces.

4b. Mz end releases

Release end moments, inspect private rotations and check static and dynamic results.

5. Static analysis

Solve the reduced system, recover the full vector and reactions, and check global equilibrium.

6. Modal analysis

Solve the generalized eigenvalue problem, expand the modes, and check residuals, scale and orthogonality.

7. Newmark transient analysis

Build the time grid, calculate initial acceleration, and examine accuracy, energy and response spectrum.

8. Element results

Recover local displacements, stresses and forces; understand their signs and how they differ from support reactions.

10. Input file format

Find precise rules for sections, units, elements, supports, loads, repeated blocks and diagnostics.

13. Interactive FEM assembly

Switch between frame stiffness and mass to inspect rotation, assembly, reduction and the Newmark effective matrix.

Laboratory approach

First inspect the diagram and make a hand prediction, then run the supplied function and explain its output. Each laboratory includes reference values and report requirements.

Quick start

Open a terminal at the repository root, add the examples directory to the Octave path and run all laboratories:

addpath(pwd);
setup;
addpath(fullfile(pwd, "reference", "examples"));
results = run_reference_examples();
Analysis through the GUI

To create or open a model, run an analysis and view the result immediately in the browser, execute from the repository root:

docker compose up --build

For the older standalone Compose command, use docker-compose up --build. Then open http://127.0.0.1:8080/preprocessor/, prepare the model and click Run analysis. GNU Octave runs inside the container, and the resulting JSON opens automatically in the postprocessor.

How to run

These commands target GNU Octave. To check everything without printing matrices, use run_reference_examples(false). Call an individual laboratory by name, for example example_07_result_recovery().

How to work through the laboratories

Open an exercise below: the diagram, input data and tasks precede the reference values. Follow the labels in the Octave output; additional inspection and plotting commands are provided where needed. PASS confirms the example’s built-in checks; your report should explain the calculation and physical meaning of the results. Predict parameter changes from formulas; editing the supplied functions is unnecessary.
