Chapter 5

Solution, reactions and equilibrium

Linear statics finds nodal displacements for which internal elastic forces balance the external load. Zero prescribed displacements allow solving only the free part without changing the full stiffness matrix.

Full and reduced systems

Original equation:

K u = F + R

Here R denotes support reactions. Partition rows and columns into free f and constrained c:

[ Kff  Kfc ] [ uf ] = [ Ff ] + [  0 ]
[ Kcf  Kcc ] [ uc ]   [ Fc ]   [ Rc ]

For the implemented homogeneous supports, uc = 0. The first block row becomes a system for the unknown free displacements:

Kff uf = Ff

Loads applied to constrained DOFs do not enter the reduced right-hand side but remain in the full F and are included in reaction recovery.

Checks before solving

validateReducedSystem checks coefficient finiteness and positive definiteness of the symmetrized Kff using Cholesky factorization. Failure usually means one of two things:

  • insufficient supports allow rigid-body motion;
  • an internal mechanism remains, for example a nodal motion is transverse to every connected truss member.

A fully constrained model is valid in statics: there are no free DOFs, all displacements are zero, and reactions carry all applied loads.

Expanding to the full vector

After solving the reduced system, a zero vector of length n is created and the computed components are inserted at indices freeDOFs:

u = zeros(numberOfDOFs, 1);
u(freeDOFs) = K(freeDOFs, freeDOFs) \ F(freeDOFs);

The full vector is needed to recover element strains, reactions and results at any node. Constrained components remain exactly zero.

Reactions and global equilibrium

After expanding the solution, reactions are calculated from the full equation:

R = K u − F

In an ideal solution, components of R at free DOFs are zero. At constrained DOFs, they give the forces and moments exerted by the supports on the model.

A small residual vector Ku − F − R alone is insufficient: it checks algebra but not the signs and positions of external forces. Therefore calculateStaticEquilibrium independently sums:

ΣFx = 0,   ΣFy = 0,   ΣMz = 0

Moments include the lever arms of nodal forces xFy − yFx and the applied nodal moments Mz of frames.

Two analytical checks

Axially loaded member

For a member of length L, area A and Young’s modulus E subjected to axial force F:

u = FL/(EA),   Rx = −F

This problem checks axial stiffness, DOF mapping, reduction, reaction sign and global balance.

Euler–Bernoulli cantilever

For a cantilever of length L subjected to transverse force P at the free end:

v = PL3/(3EI),   θ = PL2/(2EI)

Ry = −P,   Mz = −PL

One frame element reproduces this solution exactly for a nodal end force. The check is in tests/run_verification_tests.m.

Postprocessing in the offline HTML/SVG viewer

After analysis, save the model and results to a compact JSON file and open it in the MKE-F offline postprocessor. The viewer works directly through file://: no local server, npm or internet connection is required.

1. Run the analysis and export the result

Start GNU Octave from the project root and run:

addpath(pwd);
setup;

problem = StructFEProblem(fullfile('examples', 'cases', 'ANSYSBeamStatic01.txt'));
model = problem.GetAnalysisModel();
result = problem.RunStatic();

exportOptions = struct( ...
    'title', 'Static frame', ...
    'lengthUnit', 'm', ...
    'forceUnit', 'N', ...
    'momentUnit', 'N*m', ...
    'stressUnit', 'Pa', ...
    'prettyPrint', true);

exportPostprocessorData(model, result, fullfile('output', 'static-frame.json'), exportOptions);
The same analysis through the GUI

From the repository root, run docker compose up --build (or, with the older standalone command, docker-compose up --build) and open the preprocessor. Select Open TXT, load examples/cases/CasePreprocessorStatic.txt and click Run analysis. After GNU Octave finishes, the result opens automatically; the Download JSON button saves it outside the temporary container session.

exportPostprocessorData checks dimensions and finiteness, excludes global and element matrices, and writes versioned UTF-8 JSON. Unit fields are labels only: numerical values are not converted. For this SI export, the postprocessor displays coordinates and displacements in meters, forces, loads and reactions in newtons, moments in N·m, and stresses in Pa.

2. Open and adjust the view

  1. Open postprocessor/index.html in a modern Edge, Chromium or Firefox browser.
  2. Click Open JSON or drag output/static-frame.json into the dashed area. A supplied example is also available in examples/results/static-frame.json.
  3. Toggle original and deformed geometry, supports, loads, reactions, and node or element numbers in the Layers.
  4. Leave Scale = Automatic for automatic displacement magnification, or enter a positive factor manually. Use the mouse wheel to zoom and drag to pan; Reset view fits the model to the window.
  5. Click a node or element to select it and view its ID and basic data.

3. Select a static result

  • For type 112 truss elements, the Overlay list displays axial force or stress. Red indicates tension; blue indicates compression.
  • For type 113 frame elements, the Overlay list draws diagrams of N, V or M. The convention is N = −q1 with positive tension, V = −q2, while the moment varies linearly from −q3 to q6. Positive values are plotted toward the local +Y axis.
  • Deformation, arrow and diagram scales are independent and shown in the legend. An empty or unsupported diagram is replaced with a clear error message.

4. Save the illustration

Export SVG saves a scalable vector drawing with embedded styles and analysis context. For a raster image, select 1×, 2× or 4× resolution and click Export PNG. The export includes the result area and, for transient analysis, the current chart, but excludes buttons and the sidebar.

If the file does not open

Check that the supplied result is RunStatic, all values are finite, and the JSON was created by the current export function. The viewer message identifies the invalid field path, for example $.analysis.displacements. A failed load does not replace the previous valid view.

Laboratory 03. Axial member extension: displacement and support reaction

The aim is to obtain displacement from equilibrium and explain how one unknown becomes a full vector of four displacements.

Input data and notation

Length L = 2 m, cross-sectional area A = 0.01 m², modulus E = 200 GPa, force F = 1000 N. Positive X points right. Full-vector order: [u₁x; u₁y; u₂x; u₂y].

Global DOFDisplacementCondition
1u₁x0, constrained
2u₁y0, constrained
3u₂xUnknown, F applied
4u₂y0, constrained

Before running: hand calculations

  1. Identify the free displacement in the diagram and write its global number.
  2. Calculate the stiffness k = EA/L in N/m. Write the equation k·u₂x = F and find u₂x = FL/(EA).
  3. Use equilibrium of the entire member to find reaction R₁x. Construct the full displacement vector, inserting zeros at constrained DOFs.

Run in Octave

Run from the project root. The supplied function prints the results; you do not need to edit its code for this exercise.

addpath(pwd);
setup;
addpath(fullfile(pwd, "reference", "examples"));
r = example_03_static_bar();

Working with the results

  1. In the lines Fixed DOFs and Free DOFs find the numbers from your table. Number 3 denotes horizontal displacement of node 2.
  2. Compare Reduced stiffness Kff [N/m] with your EA/L, and Reduced load Ff [N] with force F. Divide the second number by the first: the result should equal the third component of Complete displacement vector [m].
  3. Compare the full vector with your prediction and the first component of Reaction vector [N] with reaction −F. Check R₁x + F = 0.
  4. Use the formula to predict the displacement change when separately doubling L, A and E. Explain why the reaction stays the same at a fixed force.
Reference values

Kff = 10⁹ N/m, Ff = 1000 N, u₂x = 10⁻⁶ m = 0.001 mm. Full vectors: u = [0; 0; 10⁻⁶; 0] m and R = [−1000; 0; 0; 0] N. Stiffness, force and displacement are related by an equation, so their numerical values cannot be compared directly with one another.

What to include in the report

The diagram with DOF numbering, the hand-derived equation, a quantity/hand calculation/Octave/units table for stiffness, displacement and reaction; explain zero components and predict the three parameter changes.

Checking distributed loads

Consistent element loads enter the full F before solving and calculating R=Ku−F. For a uniform load, the resultant is qL and acts at the midpoint of the original element; global equilibrium is also checked using these original resultants. For a cantilever, |v(L)|=|q|L⁴/(8EI), |θ(L)|=|q|L³/(6EI); free-end forces are zero.
